# Hat Game

Mobile-first multilingual team word guessing game.

## GitHub Pages
1. Create the folders/files shown below.
2. Paste each provided TXT file into its matching GitHub file, removing only the `.txt` suffix.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Structure
- `index.html`
- `css/styles.css`
- `js/app.js`
- `js/game.js`
- `js/i18n.js`
- `js/data.js`
- `js/storage.js`
- `data/words-ru.json`
- `data/words-uk.json`
- `data/words-en.json`

This first build includes the full setup/game loop and a starter word pack. The JSON structure is ready to be expanded to thousands of words per language.
